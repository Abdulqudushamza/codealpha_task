# codealpha_task
# 📊 CodeAlpha Data Analysis Tasks

## 📌 Project Description
This repository contains four data analysis tasks completed as part of the **CodeAlpha Internship Program**. Each task is implemented using Python in Jupyter Notebook and focuses on applying core data analysis techniques such as data cleaning, exploration, visualization, and interpretation of results.

## 🗂️ Project Files
- `codealpha_Task 1.ipynb` – Task 1 Web Scrapping  
- `codealph_Task 2.ipynb` – Task 2  Explarotory Data Analysis(EDA)   
- `codealph_Task 3.ipynb` – Task 3 Data Visualization
- `codealph_Task 3.ipynb` – Task 4 Data Sentiment Analysis  

Each notebook represents a separate task with its own dataset, analysis, and results.

## 🛠️ Tools & Technologies Used
- Python  
- Jupyter Notebook  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  

## 🎯 Objectives
- To apply data analysis techniques to real-world datasets  
- To perform data cleaning and preprocessing  
- To explore and visualize data for insights  
- To interpret results and draw meaningful conclusions
